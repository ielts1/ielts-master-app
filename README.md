# IELTS Master – ৩০ দিনের চ্যালেঞ্জ

## GitHub Pages এ চালু করার নিয়ম
1. github.com এ নতুন repository বানান (Public)।
2. **index.html, sw.js, manifest.json** — এই ৩টি ফাইল Upload files দিয়ে আপলোড করুন।
3. Settings → Pages → Branch: main, Folder: /(root) → Save।
4. ১–২ মিনিট পর লিংক চালু হবে। ফোনের Chrome এ খুলে “Add to Home screen” দিন।

## API Key
- অ্যাপের **সেটিংস → Gemini API Key** এ একবার বসালেই Writing, Speaking, AI-বক্স সব জায়গায় চলবে।
- কোডে স্থায়ীভাবে বসাতে চাইলে index.html এ `DEFAULT_KEY` খুঁজুন (পাবলিক repo তে বসাবেন না)।
- key বদলাতে চাইলে সেটিংসে নতুন key দিয়ে সেভ চাপুন।
